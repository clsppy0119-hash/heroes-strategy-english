# Master Plan

## 願景與核心循環

《群英戰略版》把佔地、配將、兵種判斷、資源取捨與讀戰報做成主循環；英文讓玩家更早知道、更有效率地行動。玩家完成程度測驗後，抽將組三人隊、向外佔地並從戰報調整策略。英文任務可提供情報、資源或恢復加成，但跳過仍能玩；錯字與閱讀弱點會進入複習佇列，之後重現於情報、劇情和每日任務。

## MVP 範圍

- 自適應 Web、50–100 格地圖、8–10 名原創武將、五星稀有度與抽卡。
- 三人配隊、技能、兵種克制、自動戰鬥、戰報、資源、佔地、簡化主城、每日任務。
- 程度測驗、拼字與完整字卡、閱讀、文法、錯題、基礎 SRS、能力 Dashboard。
- 固定／AI／真實文章／遊戲劇情的閱讀來源；偶發英文情報與基礎聽力。
- 獨立 AI 英文老師，只使用經授權且最小化的學習與遊戲摘要。

## 明確延後

多人、PVP、同盟、攻城、外交、賽季、口說、寫作、自訂教材。考試目標先保留資料欄位，學測、TOEIC、GEPT、IELTS 題庫不在 v0.1。

## 成功指標

- 新玩家 10 分鐘內完成首次佔地並看懂勝敗原因。
- 不作答也能完成核心循環；英文收益清楚但不形成學習牆。
- 7 日內至少 60% 已學字詞曾在另一情境重現。
- 戰鬥與學習事件可追溯，戰鬥可用固定 seed 重播。

GitHub repo 內文件、issue、PR 與提交為唯一真實來源。ChatGPT 負責產品／架構拆解；Codex 實作與驗證；Claude 提供 review，建議落到 GitHub 才生效。

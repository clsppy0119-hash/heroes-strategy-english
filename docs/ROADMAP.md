# 路線圖

實際的路線圖在 **[#3 開發路線圖：五刀縱切 v0.1 → v1.0](https://github.com/clsppy0119-hash/heroes-strategy-english/issues/3)**，那裡是唯一真實來源。這份文件只解釋為什麼換了排法，以及舊的 M1–M6 對到哪裡。

## 為什麼換

舊的排法是橫切：把核心系統全做完，再把學習系統全做完，再把 AI 全做完，最後整合測試。工作量沒問題，問題是第一個可玩版本落在專案末端，而「學習能不能讓遊戲更好玩」這個最底層的假設要等到那時才第一次接觸真人。

新的排法是縱切：每一刀都從玩法穿到資料層，結束時都有人能玩、有數字可看、有事先寫好的喊停條件。填的格子一樣多，順序不同。

## 舊 M1–M6 對到哪

| 舊 | 新 | 備註 |
| --- | --- | --- |
| M1 可玩的核心循環 | **v0.1 一場仗** | 範圍砍到 3×3 地格、一種資源、一種部隊、二十個單字。56 格與三人隊伍延後。 |
| M2 帳號與持久化 | **v0.2 一座城**（持久化）＋ **v0.3 一個對手**（帳號） | 帳號體系跟著非同步 PVP 一起做，因為在那之前沒有跨裝置的必要。 |
| M3 武將與主城 | **v0.2**（主城建築）＋ **v0.5 一個賽季**（武將與抽卡） | 抽卡是變現與長線動能系統，核心循環沒站穩前做只會讓學習退化成刷票。 |
| M4 學習核心 | 拆進 **v0.1 → v0.5** | 每一刀加一種題型與一層複習機制，不整包做。 |
| M5 世界記憶循環 | **v0.3** 起 | 學過的字重現在情報與戰報裡。 |
| M6 AI 老師與上線 | **v0.3**（AI 老師）＋ **v1.0**（上線） | AI 成本熔斷不在這裡，它在 v0.1 就要有位置。 |

## v0.1 的四項橫向約束

不屬於任何一刀，但第一天就在，因為晚做等於全面返工：i18n key、埋點 schema、`src/core` 可搬到伺服器、AI 成本熔斷。細節見 [README](../README.md) 與 [#4](https://github.com/clsppy0119-hash/heroes-strategy-english/issues/4)。
